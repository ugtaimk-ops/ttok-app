APK 다운로드
🍎 아이폰 IPA (비서명)

아이폰은 Apple 정책상 앱을 다운로드만 받아서는 바로 설치되지 않아요. 아래 IPA를 받은 뒤, PC에서 Sideloadly 또는 AltStore를 이용해 설치해야 합니다.

IPA 다운로드
  1. PC에 Sideloadly 설치 (sideloadly.io)
  2. 아이폰을 PC에 USB로 연결
  3. 위에서 받은 .ipa 파일을 Sideloadly에 끌어다 놓기
  4. Apple ID 입력 후 설치 (무료 계정도 가능, 7일마다 재설치 필요)

이 페이지는 항상 최신 빌드로 갱신됩니다.
베타 테스트 전용이며 공식 배포판이 아닙니다.
