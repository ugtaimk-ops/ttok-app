똑타임 개인정보처리방침

똑타임은 집중 타이머, 학습 기록, 시험 일정 확인 및 공부방 기능을 제공하기 위해 필요한 정보를 처리합니다.

처리하는 정보와 목적

  • 계정: 이메일 주소와 Firebase 사용자 ID를 로그인, 계정 연동 및 인증에 사용합니다.
  • 프로필: 사용자가 입력한 이름, 학교, 학년, 반, 프로필 사진 URL을 프로필 표시, 학교방 검색 및 계정 연동에 사용합니다.
  • 학습 정보: 타이머 설정과 집중 기록은 기본적으로 현재 기기에 저장됩니다. 사용자가 시험 일정과 연동 학습을 사용할 때 관련 기록은 Firebase에 저장될 수 있습니다.
  • 공부방: 방 입장 시 이름, 학교 식별 정보, 참여 상태, 공부 시간을 다른 참여자나 순위 화면에 표시할 수 있습니다. 음성 및 비공개방 영상은 사용자가 기능을 켰을 때 참여자 간 통신에 사용됩니다.
  • 알림: 사용자가 허용한 경우 시험 일정 및 타이머 완료 알림을 기기에서 표시합니다.

권한과 외부 서비스

카메라와 마이크 권한은 공부방에서 해당 기능을 켰을 때 사용합니다. 계정 인증과 일부 학습 정보 저장에는 Google Firebase를 사용합니다. 학교 검색에는 똑 서비스 서버와 학교 정보 제공 API를 사용합니다. 실시간 공부방 연결에는 똑타임의 방 서버를 사용합니다.
